# Agente de Revisión de Código

Agente construido sobre OpenCode que revisa código de un repositorio real,
detectando problemas de estilo, errores potenciales y cuestiones de seguridad,
emitiendo retroalimentación estructurada con criterio razonado
(no un flujo automatizado tipo linter).

## Estado del proyecto
En construcción — Fase II de la Hoja de Ruta de Incorporación Técnica, ICIMAF.
Desarrollado inicialmente en entorno local; migración a servidor pendiente (Fase I).

## Documentación
- `docs/decisiones.md` — ADRs (decisiones de arquitectura)
- `docs/arquitectura.md` — documento técnico (se llena progresivamente)
- `prompts/` — historial versionado de prompts del agente
